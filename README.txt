SHAMIM Ag Consulting website: free setup (only cost is the domain, about $10-12/yr)

1) CONTACT FORM (free): Sign up at formspree.io and create a form. Copy the form ID
   (e.g., xyzabcd) and replace YOUR_FORM_ID in index.html. Requests will go to your email
   (free plan has a monthly submission limit).
2) HOSTING (free): Create a GitHub account and a new public repository (e.g., shamimag-site).
   Upload index.html, logo.jpg, and favicon.png. Go to Settings > Pages > Deploy from branch: main.
   The site will be live at https://<username>.github.io/shamimag-site
   (Cloudflare Pages or Netlify also work and are free.)
3) DOMAIN (~$10-12/yr): Buy shamimag.com (or similar) from Cloudflare Registrar, Porkbun, or Namecheap.
   In GitHub Pages, add the custom domain and set the DNS records shown there. Enable "Enforce HTTPS".
4) BUSINESS EMAIL (free): Use Cloudflare Email Routing to forward info@shamimag.com to your Gmail.
   You can also set up Gmail to "Send mail as" that address.
5) EDIT: Replace the phone number (859) 000-0000 and email in index.html.
6) GOOGLE: Create a free Google Business Profile so farmers can find you in Maps.
